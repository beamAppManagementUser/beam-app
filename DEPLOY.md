# Deploying Beam Veda to Cloudflare Workers (No R2 Required)

This guide walks you through deploying your app to Cloudflare's free tier. **No payment method needed** — everything runs on D1 (database) and Workers (compute).

## Prerequisites

1. A Cloudflare account (free — sign up at cloudflare.com)
2. Node.js installed on your computer
3. Your GitHub repo with the code
